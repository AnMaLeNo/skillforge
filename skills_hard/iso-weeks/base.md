# Objectif

`events.txt` contient une date ISO par ligne. On veut `weeks.json` : un objet JSON `{"AAAA-Www": nombre}` qui compte les événements par semaine ISO 8601 (l'année est l'année ISO de la semaine, pas l'année civile).

Vérifie le résultat avant de conclure.
