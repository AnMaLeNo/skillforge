# Procédure

1. Écris `to_roman` avec la table des 13 symboles (M, CM, D, CD, C, XC, L, XL, X, IX, V, IV, I).
2. Écris `from_roman` qui additionne les valeurs avec la règle de soustraction.
3. Ajoute la validation : `from_roman` lève `ValueError` si `to_roman(valeur) != s`.
4. Teste sur quelques exemples.
