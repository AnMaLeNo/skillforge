# Objectif

On a besoin d'un module `roman.py` exposant `to_roman(n)` (1..3999) et `from_roman(s)`. `from_roman` doit lever `ValueError` pour toute chaîne qui n'est pas un numéral romain canonique (ex. `IIII`, `VX`, `IC`, `MMMM`, chaîne vide), et `to_roman(from_roman(s)) == s` pour tout numéral valide.

Vérifie le résultat avant de conclure.
