# Objectif

`intervals.txt` contient un intervalle entier fermé `a b` par ligne, dans le désordre. On veut `merged.txt` : les intervalles fusionnés (deux intervalles qui se chevauchent ou se touchent n'en font qu'un), un par ligne `a b`, triés par début.

Vérifie le résultat avant de conclure.
