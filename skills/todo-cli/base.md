# Objectif

On veut un petit gestionnaire de tâches en ligne de commande : `python3 todo.py add "texte"` ajoute une tâche, `python3 todo.py list` affiche toutes les tâches (une par ligne, dans l'ordre d'ajout). Les tâches doivent survivre entre deux exécutions (stockage dans `todo.json`).

Vérifie le résultat avant de conclure.
