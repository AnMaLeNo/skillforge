# Objectif

`app.log` a une ligne par événement, avec un niveau (INFO, WARN, ERROR, DEBUG) en deuxième champ. On veut `summary.json` : un objet JSON {niveau: nombre de lignes} pour chaque niveau présent.

Vérifie le résultat avant de conclure.
