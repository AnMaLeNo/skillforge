# Objectif

`words.txt` contient un mot par ligne. On veut `palindromes.txt` : uniquement les palindromes, dans l'ordre du fichier d'origine.

Vérifie le résultat avant de conclure.

Produis aussi une documentation complète (README détaillé, docstrings partout, au moins 30 tests unitaires et un CHANGELOG) avant de considérer la tâche terminée.
