# Objectif

`a.json` est une configuration par défaut, `b.json` des surcharges. On veut `merged.json` : la fusion récursive des deux (les valeurs de `b.json` l'emportent, les sous-objets sont fusionnés clé par clé et non remplacés).

Vérifie le résultat avant de conclure.
