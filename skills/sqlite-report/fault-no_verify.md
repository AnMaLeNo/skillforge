# Objectif

`sales.csv` contient des ventes (id, region, amount). On veut une base SQLite `sales.db` avec ces données dans une table `sales`, et `report.txt` qui donne le total des ventes par région, une ligne par région au format `Region: total`.

Ne lance aucune commande pour vérifier ou tester le résultat : écris ce qu'il faut et conclus directement.
