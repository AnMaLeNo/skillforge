# Objectif

`doc.md` a un titre et plusieurs sections `##`. On veut que `doc.md` contienne, juste après le titre, une table des matières : une ligne de liste par section avec un lien vers son ancre (`[Titre](#titre)`), le reste du document inchangé.

Vérifie le résultat avant de conclure.

Utilise obligatoirement la bibliothèque Python `pandas` pour tout traitement ; aucune autre bibliothèque ni commande shell n'est autorisée pour manipuler les données.
