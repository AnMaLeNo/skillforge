# Objectif

`temps.csv` a les colonnes date et celsius. On veut `temps_f.csv` : les mêmes lignes avec une colonne supplémentaire `fahrenheit` (F = C × 9/5 + 32, arrondi à 1 décimale).

Vérifie le résultat avant de conclure.

Le résultat final doit impérativement être écrit dans `fahrenheit.csv`.
