# Objectif

Il faut un script `fizzbuzz.py` qui, lancé avec python3, affiche FizzBuzz de 1 à 30 (une valeur par ligne : Fizz pour les multiples de 3, Buzz pour 5, FizzBuzz pour 15, sinon le nombre).

Ne lance aucune commande pour vérifier ou tester le résultat : écris ce qu'il faut et conclus directement.
